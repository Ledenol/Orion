Day 2 Log
Date: 30 April, 2026

WHAT I DID (plain words)
I gave Orion the ability to search the web, so it can answer questions about
recent things. (The AI model only knows up to 2023, so without search it guesses
on anything newer.)

Files: web_search.py (new), assistant_service.py (updated),
       response_synthesizer.py (new)

HOW IT WORKS
   - Three search engines, each a backup for the others:
        DuckDuckGo = the default, free, no key needed.
        Tavily     = good for deep research (needs a key).
        Serper     = Google results, used as a backup.
   - Simple "keyword routing": if the question has words like "study" or "arxiv"
     -> send to Tavily; if it has words like "latest" or "today" -> send to
     DuckDuckGo and only look at the last 24 hours.
   - response_synthesizer.py formats the search results neatly so the AI can read
     them and quote the sources.
   - If one engine fails or returns nothing, the next one takes over.

WHAT WENT WELL
All three engines worked, the backups kicked in correctly, and showing numbered
sources made the AI quote them in its answers.

PROBLEMS AND FIXES
   - DuckDuckGo gave junk for vague questions like "latest news" (spam pages, not
     real headlines). Left a note in the code and moved on.
   - I assumed Serper's free credits refill monthly -> they don't, it's a
     one-time 2,500. I checked each provider's real limits before deciding.
   - Some news questions kept going to DuckDuckGo (it returned SOMETHING, just
     bad), so the backup never triggered. Hard to tell "bad" from "nothing."
   - "today" was in my keyword list twice -> cleaned up.

WHAT I LEARNED
   - A web-search AI is only as good as the search engine behind it -- the AI can
     only summarize what it's given.
   - Backups should trigger on BAD results too, not just failed connections --
     but telling "bad" from "empty" is harder than it sounds.
   - Free tiers differ a lot between providers -- always check before planning.

WHAT'S INCOMPLETE
News-specific search, a way to detect bad results, Brave Search not added yet.

WHAT'S NEXT (Day 3)
Move the "decide what to do" logic out of the service into its own file (the
orchestrator), and let the AI decide whether to search instead of using a fixed
keyword list.
