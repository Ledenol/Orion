Day 1 Log
Date: 29 April, 2026

WHAT I DID (plain words)
I built the first, simplest version of Orion: a text assistant you talk to in
the terminal. You type a question, it sends it to an AI model online (through a
service called Groq), and prints the answer back.

Files: .env, .gitignore, main.py, openai_client.py, groq_client.py,
       assistant_service.py

HOW IT WORKS
   - main.py            = the chat loop (ask question -> print answer -> repeat).
   - groq_client.py     = the part that actually talks to the AI over the internet.
   - assistant_service.py = a thin middle layer between the chat loop and the AI.
   - .env               = where I keep my secret API key, out of the code.
The model I used: llama-3.1-8b-instant.
The instruction I gave it: "You are Orion, a helpful research assistant."

WHAT WENT WELL
It worked, after fixing a few small errors.

PROBLEMS AND FIXES
   - OpenAI's API costs money, so I switched to Groq's free option.
   - Some Groq models had been shut down; I tried a few and settled on
     llama-3.1-8b-instant.
   - I kept the model name in the .env file so it's easy to change.

WHAT I LEARNED
   - How to call an AI API: the "messages in, response out" pattern.
   - The different Groq models and their limits.

WHAT'S NEXT (Day 2)
This model only knows things up to 2023. Ask about anything newer and it makes
stuff up. So next I'll add a web-search tool so Orion can look things up.
